# ATLAS v0.3.3 Alpha - Modal de producto con galeria

## Archivos que debes reemplazar

- `index.html`
- `css/estilos.css`
- `css/responsive.css`
- `js/app.js`

No reemplaces `js/productos.js` ni las carpetas de imagenes.

## Funciones agregadas

- Ventana de detalles para cada producto.
- Galeria con todas las fotografias registradas.
- Miniaturas seleccionables.
- Flechas anterior y siguiente.
- Contador de fotografias.
- Cierre con X, fondo oscuro o tecla Escape.
- Navegacion con flechas izquierda y derecha del teclado.
- Bloqueo de desplazamiento mientras el modal esta abierto.
- Adaptacion para computador, tableta y celular.

## Prueba recomendada

1. Abre el proyecto con Live Server.
2. Presiona `Ctrl + F5`.
3. Baja al catalogo.
4. Pulsa `Ver detalles` en cada producto.
5. Prueba miniaturas, flechas, X, fondo oscuro y Escape.
